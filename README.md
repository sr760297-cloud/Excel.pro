Project Overview
This project is an Excel-based Government Schemes Dashboard created to analyze government scheme data using Excel, Pivot Tables, and Charts. The dashboard provides a simple visual overview of beneficiaries, budget, applications, approvals, categories, states, and scheme launch years.
Key Features
- 100 government scheme records
- 15 data columns
- Pivot Table-based analysis
- Top 10 schemes by beneficiaries
- Top 10 schemes by budget
- Schemes by category
- Top states by beneficiaries
- Schemes by launch year
- Applications vs Approved analysis
- 4 KPI cards
- Interactive-style dashboard layout with 6 charts
- Clean dashboard design inspired by a sales dashboard
Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Data Analysis
- Dashboard Design
Dashboard KPIs
- Total Beneficiaries
- Total Budget
- Total Applications
- Total Approved Applications
